# Almeida & Ferraz Advocacia — Landing Page Institucional

Landing page institucional desenvolvida para representar um escritório de advocacia com posicionamento premium, linguagem profissional e foco em geração de contato via WhatsApp.

## Visão do Projeto

Este projeto foi pensado para transmitir:

- credibilidade
- autoridade
- sofisticação
- clareza na comunicação
- conversão com experiência elegante

O resultado é uma página de alta percepção de valor, com identidade visual amadeirada, composição executiva e navegação fluida.

## Destaques

- Hero section cinematográfica com forte impacto visual
- Direção de arte premium para ambiente jurídico institucional
- Estrutura orientada à conversão com CTAs estratégicos
- Fluxo de atendimento apresentado de forma clara e profissional
- Seção de profissionais para reforço de confiança
- Abertura de contatos em nova guia com mensagem pronta no WhatsApp
- Navegação por âncoras com rolagem suave e seção ativa destacada
- Layout totalmente responsivo para desktop, tablet e mobile

## Tecnologias Utilizadas

- React
- Vite
- Tailwind CSS
- CSS customizado para microinterações e refinamento visual
- Lucide React (ícones)

## Diferenciais do Projeto

- Design institucional premium voltado ao segmento jurídico
- Hierarquia tipográfica refinada para leitura e autoridade
- Microinterações discretas e profissionais (hover, reveal, transições)
- Navbar dinâmica com comportamento moderno ao scroll
- SEO básico e metadados de publicação já preparados

## Responsividade e UX

O projeto foi otimizado para diferentes resoluções, com:

- empilhamento elegante de grids e cards
- escalas tipográficas adaptativas
- ajustes de espaçamento para ritmo visual consistente
- menu mobile funcional com boa usabilidade

## Como Rodar Localmente

```bash
npm install
npm run dev
```

Para gerar build de produção:

```bash
npm run build
```
